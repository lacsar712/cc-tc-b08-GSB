# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

放炮后单点毫米值会突然飞出，值班另设一张**抽稀台**（页眉「抽稀台」进入专页，不只是总表一盏灯）：抽稀开启时，交单口按同部位相对取样窗的中位跳变拦飞点，整份退回、绝不入队、绝不补填中位值冒充；关停后只不再拦新点，旧拦截履历仍可翻。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 抽稀台规则

- 开关与取样窗在专页左列：`enabled`、窗长 `window_size`（2～50）、中位跳变阈值 `threshold_mm`（mm）。
- 提交读数时，若抽稀开启，取**同部位**（拱顶 / 边墙分别取窗）最近 N 笔**已准入**读数的中位值；新读数与中位的偏离**达到阈值（含贴门槛）即判飞点**，整份退回，仅写入拦截履历，不进待认领队列，也不生成任何补填行。
- 窗内不足 2 笔时不做飞点判定（无法确定相对中位）。
- 交单口在同一事务内取 `pg_advisory_xact_lock` 串行完成「读配置→取窗→判跳→入库」，贴着门槛几乎同时进来的两笔至多进队一笔（线程锁为单进程多线程兜底）。
- 关停抽稀：不再拦新读数（同类飞点可正常进队出结论）；右列历史履历保留可翻。
- 边墙锤击飞点与拱顶读数走同一张抽稀台，提交时带 `part` 区分。

### 抽稀专页布局

- 左列：运行/停用灯号、开关按钮、取样窗长与跳变阈值（巡检员只读）。
- 中列：最新一笔拒收样例（读数、窗内中位、跳变量、阈值快照、退回原因）。
- 右列：全部拦截履历，关停后仍可翻。

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | - | 登录取 JWT |
| GET | `/api/logs` | 登录 | 总表（含部位 part） |
| POST | `/api/logs` | 测量员 | 交单口；抽稀开启时飞点返回 400 且 `rejected=true`，不入库 |
| GET | `/api/thin/config` | 登录 | 抽稀开关与取样窗 |
| PUT | `/api/thin/config` | 测量员 | 改开关/窗长/阈值；巡检员 403 |
| GET | `/api/thin/rejects` | 登录 | 拦截履历（关停后仍可查） |

POST `/api/logs` body：`{"chainage": "K20+050", "part": "拱顶|边墙", "delta_mm": 1.2}`，`part` 缺省为拱顶。
