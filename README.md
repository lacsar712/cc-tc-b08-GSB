# 隧道收敛测缝台

测量员登记里程桩号与收敛毫米值。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

放炮后单点毫米会突然飞出去，为此配了一张**能停能开的抽稀台**：页眉导航点进「抽稀专页」，左列是开关与取样窗，中列是最新一批拒收样例，右列是已拦住的履历。抽稀开着时，相对窗内中位跳变超过门槛的飞点、以及同一测点（桩号+部位）在取样窗内的重复交单，都会**整份退回**——不进收敛队列，只进拦截履历；关掉以后新单不再拦截，旧履历仍可翻。掌子面放炮与边墙锤击的飞点走同一张抽稀台。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16

## 抽稀台

- 开关与参数落库（`thinning_state` 单例），默认关、取样窗 3600 秒、跳变门槛 5.0 mm。
- 规则（仅开着时生效，全测点共用）：
  - `median_jump`：相对窗内已进队读数的中位数跳变超过门槛 → 整份退回；
  - `window_dup`：同一测点（桩号+部位）在取样窗内已有一笔进队 → 整份退回；贴着门槛几乎同时进来的两笔至多进队一笔（进程内互斥 + 行级 `FOR UPDATE` 串行化）。
- 被退回的笔不进 `convergence_logs`，记入 `thinning_rejections` 履历；页面中位数字由接口实时计算，不私填。

### 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/thinning` | 抽稀状态 + 当前窗内中位/样本数（登录即可） |
| PUT/POST | `/api/thinning` | 改开关/取样窗/门槛（仅测量员） |
| GET | `/api/thinning/rejections` | 拦截履历（登录即可；别名 `/api/thinning/history`） |
| POST | `/api/logs` | 交单口：单笔 `{chainage, section, delta_mm}` 或整份 `{items: [...]}`；被抽稀拦截返回 422 与退回原因 |

`section` 部位缺省为 `掌子面`，边墙测点传 `边墙`，走同一套抽稀规则。
